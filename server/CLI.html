Mission Taxonomy

One control plane, multiple industry evaluators

MOLECULAR / BIOLOGICAL

PDB / FASTA → protein folding, binding, antibodies
SDF / MOL2 → ligand docking and conformational search
mRNA / RNA → stability, structure, delivery
Protein Design → de novo sequences and structures

MATERIALS / CRYSTAL

CIF / XYZ → batteries, catalysts, semiconductors
MOF / Adsorption → CO₂ capture and gas separation
Crystal Lattice → ion diffusion, stability, defects
Materials CAMEO → deterministic evaluator pipelines

ENGINEERING / TOPOLOGY

Graph / JSON → chip interconnects and DAGs
CAD / Mesh → aerospace and automotive geometry
Physics → thermal, aero and structural optimisation
Topology CAMEO → objective scoring against constraints

INDUSTRIAL / ENERGY

Catalyst → adsorption and reaction pathways
Hydrogen → electrolyzers and storage materials
Mining → flotation and mineral separation
Subsurface → fluid / reservoir geometry
