qFoldIT Game Modes

5 modes for different scientific tasks
Research Campaign

Narrative, multi-stage mode for long-term research — protein design, new materials, batteries, industrial optimization.

MCP: OpenStructure, QSAR/ADMET, Materials, Digital Twin Algorithms: lDDT, QSAR, ADMET, geometry Standards: ISO/IEC 17025, OECD GLP, FAIR
Arena Challenge

Timed competitive mode for optimization under pressure — leaderboards, contests, records.

MCP: OpenStructure, Quantum Optimization, Mission Registry Algorithms: QAOA, VQE, CVaR, search Standards: ISO/IEC 25010, 21 CFR Part 11
Co‑op Lab

Teamwork on a scientific task — collaborative review, refinement, validation.

MCP: Mission Registry, RBAC, OpenStructure Algorithms: consensus, conflict resolution, multi-criteria optimization Standards: ISO/IEC 27001, ISO 23247, ISO 19650
Sandbox Lab

Free exploration for prototyping, learning, and demonstrations.

MCP: Sandbox, OpenStructure, Domain Adapters Algorithms: L‑systems, Monte‑Carlo, generative rules Standards: FAIR, ISO/IEC 25010
Validation Duel

Direct competition with an invisible reference — blind testing, challenges.

MCP: CAMEO Validation Gateway, OpenStructure, Reward Policy Algorithms: blind checking, threshold values, ranking Standards: 21 CFR Part 11, auditability

Security architecture — trust zones

separation of responsibilities
1. Public zone
Game clients, web interfaces — contain no confidential data.
2. Gateway
Authenticated calls, schema validation, rate limiting, request signatures.
3. Corporate zone
Tenant management, mission orchestration, policies, audit.
4. Scientific zone
Closed OPENSTRUCTURE services, protected reference data.
5. Commercial zone
Payment and reward services — separated from science.
Principle: no game client can access the reference structure; the scientific service does not make commercial decisions; the public STATE does not contain private data.

Unified pipeline

from order to validation
1. The customer (B2B) defines the task and uploads the data ↓
2. INDUSTRIAL‑CAMEO compiles the task into a UAG ↓
3. Adapters generate game missions (UEFN, Unity, UNIGINE, Web, Standalone) ↓
4. Players solve the task through gameplay ↓
5. OPENSTRUCTURE (AlphaFold, VQE, ZairaChem, etc.) validates the solutions ↓
6. The customer receives a scientifically validated result and pays for the valid solution.
Result: acceleration of R&D by 3–10 times, access to thousands of player-solvers, complete transparency and reproducibility.
